# 🍲 FoodShare — Food Donation Platform

**Reducing Food Waste, Sharing Food, and Supporting Communities.**

FoodShare is a web-based food donation platform designed to help reduce food wastage by connecting restaurants with NGOs that can distribute surplus food to people in need.

The platform provides a simple way to share available food, claim donations, and verify NGOs, encouraging responsible food management and community support.

## 🌟 Features

- **Food Donation:** Restaurants can upload details of surplus food available for donation.
- **Food Claiming:** NGOs can view available food donations and claim food according to their requirements.
- **NGO Verification:** A verifier can review and verify NGOs to support a more reliable donation process.
- **User-Friendly Interface:** A simple interface designed to make the food donation process easier.
- **Waste Reduction:** Encourages the effective use of surplus food instead of letting it go to waste.

## 👥 User Roles

### 1. Restaurant
Restaurants can share details of surplus food that is available for donation.

### 2. NGO
NGOs can explore available food donations and claim food for distribution to people in need.

### 3. Verifier
The verifier is responsible for checking NGO details and supporting the verification process.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/manishsharma3574/foodshare.git
```

**2. Open the project folder**

```bash
cd foodshare
```

**3. Navigate to the frontend folder**

```bash
cd client
```

**4. Install dependencies**

```bash
npm install
```

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.
